# Hindustani Music Swarlipi Keyman Keyboard

A custom Keyman keyboard layout designed for quickly typing Hindustani classical music notation (Swarlipi) using a standard QWERTY input.

## Keyboard Mapping Reference

| Key | Output Swara / Symbol | Type / Description |
| --- | --- | --- |
| `s` / `S` | सा | Shuddha Sa |
| `r` | रे | Shuddha Re |
| `R` | रे॒ | Komal Re |
| `g` | ग | Shuddha Ga |
| `G` | ग॒ | Komal Ga |
| `m` | म | Shuddha Ma |
| `M` | मं | Teevra Ma |
| `p` / `P` | प | Shuddha Pa |
| `d` | ध | Shuddha Dha |
| `D` | ध॒ | Komal Dha |
| `n` | नि | Shuddha Ni |
| `N` | नि॒ | Komal Ni |
| `a` / `A` | ा | Aa Matra |
| `,` | ़ | Nukta |
| `.` | ं | Anusvara |
| `\|` or `(` or `)` | । | Purna Viram (Beat/Phrasing boundary) |
| `i` or `!` or `*` or  `` ` `` | ् | Halant (Virama / Half-note connector) |

## Installation Guide

To use this keyboard, you must first download the `.kmp` (Keyman Package) provided in this Repository

### 📱 Mobile Installation (Android & iOS)

1. **Install Keyman:** Download and install the official **Keyman** app from the Google Play Store or Apple App Store.
2. **Install into Keyman:**
* **Android:** Open the Keyman app > Go to **Settings** > **Language Settings** > **+ Add Language/Keyboard** > Tap the menu/three dots and choose **Install from local file** (or browse to your `.kmp` file).
* **iOS:** Open the `.kmp` file using the iOS Files app, tap the share icon, and select **Open in Keyman**. Follow the on-screen prompts to install.
3. **Enable Keyboard:** Enable Keyman as a system-wide keyboard in your device's system settings under *Languages & Input* (Android) or *Keyboards* (iOS).

### 💻 Desktop Installation (Windows & macOS)

1. **Install Keyman:** Download and install Keyman Desktop from the official website ([keyman.com](https://keyman.com)).
2. **Install the Layout:** Double-click your custom `.kmp` file. Keyman will automatically open an installation dialog.
3. **Complete Setup:** Click **Install** and follow the prompts. You can now toggle to this layout using `Win + Space` (Windows) or `Ctrl + Option + Space` (macOS).
